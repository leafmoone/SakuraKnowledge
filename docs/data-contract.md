# Contract v1 (baseline)

Manifest: JSON object with sources array and optional index_episodes=false. TOML parses too, but JSON is recommended because unknown metadata must remain null, not an invented value. Required fields are defined in `storage.REQUIRED_SOURCE`: source_id, provider, dataset_role, repo (no credentials), upstream_revision, asset_name, upstream_digest, local_sha256, source_declared_cutoff, exported_at, fetched_at_utc, inspected_at_utc, schema_version, importer_version, mapping_generator_revision, input_file_inventory, counts, source_references, refresh_status, code_license, data_license, path, adapter. Only adapter=contract-jsonl-v1 is accepted. Paths resolve relative to manifest; digests are SHA256 hex. Metadata presence is checked; strict field typing/inventory validation remains incomplete.

JSONL entity: key={kind,namespace,value}, optional type/locator, aliases=[{text,language,type,status,evidence_id}], documents=[{title,original,language,status,evidence_id}], occurrences=[{dataset,group,frequency}]. Evidence IDs default to source-id:file-sha:line:N. Additional alias/document/occurrence fields remain in payload. General top-level entity raw metadata is not yet preserved: do not normalize real dumps with this baseline when that would lose source fields.

JSONL link: record_type=link, src/dst full keys, relation, method, verification_status in native/redirect/candidate/verified/conflict. Original link payload and source line locator survive. Statuses on alias/doc: source_backed/generated_from_evidence/unverified_draft/no_reference/conflict/failed. Only the first two are queried by default. Candidates are never promoted by the importer. A trusted upstream normalization producer is required; asserted verified input is not itself human fact review.

Output result: contract_version, snapshot, query, status, entry_key, tag_key, canonical, candidates, descriptions, relations, citations, warnings. Descriptions contain source_id/evidence_id, original text limited to 4000 characters. Search candidate descriptions retain citations locally. Alias-only exact hits still need complete top-level citation assembly. Limits: query 4096 characters, 256 tokens; indexed document 100000 characters; topk/related max 100. Episode keys import while episode FTS defaults off.
